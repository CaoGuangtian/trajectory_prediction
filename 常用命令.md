# 常用命令

以下命令均在项目根目录执行。

## 激活虚拟环境

```powershell
conda activate traj-pre
```

## 启动轨迹可视化

```powershell
python -s -m apps.experiment_viewer.app
```

浏览器访问：<http://127.0.0.1:8050>

按 `Ctrl+C` 停止程序。

## 运行测试

```powershell
python -s -m unittest discover -s tests -p "test*.py"
```

## 运行位置保持基线

只运行 subset_1：

```powershell
$env:PYTHONPATH = "src"
python -s -m trajectory_prediction.cli.evaluate_position_hold --subset 1 --overwrite
```

运行全部已准备好的 subset：

```powershell
$env:PYTHONPATH = "src"
python -s -m trajectory_prediction.cli.evaluate_position_hold --all --overwrite
```

## 运行恒速直线外推基线

只运行 subset_1：

```powershell
$env:PYTHONPATH = "src"
python -s -m trajectory_prediction.cli.evaluate_constant_velocity --subset 1 --overwrite
```

运行全部已准备好的 subset：

```powershell
$env:PYTHONPATH = "src"
python -s -m trajectory_prediction.cli.evaluate_constant_velocity --all --overwrite
```

## 运行 IMM-CV-CT-Singer 模型

当前本地资源配置只运行 `subset_1`：

```powershell
$env:PYTHONPATH = "src"
python -s -m trajectory_prediction.cli.evaluate_imm_kalman --subset 1 --overwrite
```

运行带因果机动门控和最近 31 点 OLS-CV 回退的改进版：

```powershell
$env:PYTHONPATH = "src"
python -s -m trajectory_prediction.cli.evaluate_imm_kalman --config configs/models/imm_cv_ct_singer_gated_v2.yaml --subset 1 --overwrite
```
