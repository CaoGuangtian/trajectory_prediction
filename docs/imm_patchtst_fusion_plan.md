# IMM–PatchTST 融合模型设计计划

> 实现状态：第一版 `Standard IMM + PatchTST Raw` 残差融合、因果 IMM 缓存、训练/评估 CLI 与合成测试已经在本地实现。运行说明见 `docs/imm_patchtst.md`。尚未生成真实数据缓存，也未启动本地训练。

## 研究定位

论文题目为“深度学习与多模型卡尔曼滤波融合的飞行轨迹预测方法”。当前项目已经实现独立的多模型滤波方法，并正在训练独立的 PatchTST 深度学习模型。它们首先作为两类基线，用于分别回答：

- 多模型滤波单独能够达到什么效果；
- 深度学习单独能够达到什么效果；
- 融合模型是否真正优于两个独立分支。

仅比较 IMM 与 PatchTST 仍属于基线实验。后续工作的核心应是提出具有明确融合位置、可解释机制和完整消融实验的融合模型。

## 首选方案：模式感知的 IMM–PatchTST 残差融合

第一版建议采用 IMM 物理预测加 PatchTST 残差补偿：

\[
\hat Y_{\mathrm{IMM}}=\operatorname{IMM}(X)
\]

\[
\Delta\hat Y=f_\theta(X,\hat Y_{\mathrm{IMM}},\mu,P)
\]

\[
\hat Y_{\mathrm{fused}}=\hat Y_{\mathrm{IMM}}+\Delta\hat Y
\]

其中：

- \(X\) 是预测原点之前的历史轨迹；
- \(\hat Y_{\mathrm{IMM}}\) 是 IMM 的未来多步预测；
- \(\mu\) 是 IMM 的模型概率；
- \(P\) 是 IMM 的预测协方差或不确定性；
- \(f_\theta\) 是负责预测残差的 PatchTST；
- \(\Delta\hat Y\) 是对 IMM 预测的修正量。

PatchTST 的训练目标改为：

\[
Y_{\mathrm{residual}}=Y_{\mathrm{true}}-\hat Y_{\mathrm{IMM}}
\]

这种设计让 IMM 负责稳定、可解释的运动学外推，让 PatchTST 重点学习 IMM 难以表达的转弯、阶段切换、非线性加减速和长时域累计偏差。

## 分阶段实现

### 第一阶段：最小残差融合

只输入历史轨迹和 IMM 未来预测，由 PatchTST 预测 IMM 残差。先回答“学习 IMM 残差是否优于直接预测未来轨迹”，暂不加入所有内部滤波特征。

### 第二阶段：引入多模型信息

在最小版本有效后，逐项引入：

- 各子模型概率；
- 当前占优运动模式；
- 创新或观测残差；
- 预测协方差；
- 模式切换信息和门控状态。

对应的研究问题是：IMM 的模式与不确定性信息能否帮助深度模型识别“何时、如何修正”物理预测。

### 第三阶段：动态门控融合

如果残差模型有效，可进一步学习不同预测时域的融合权重：

\[
\hat Y_h=\alpha_h\hat Y_{\mathrm{IMM},h}+(1-\alpha_h)\hat Y_{\mathrm{PatchTST},h}
\]

短时域通常更依赖 IMM；长时域、模式切换或 IMM 不确定性较高时，可以提高深度模型权重。门控权重应由历史状态、模型概率和协方差等因果信息产生。

## 推荐实施顺序

1. 完成 PatchTST Raw 与 PatchTST Causal Smooth 的训练和独立评估。
2. 冻结数据划分、预测原点、归一化规则和评价协议。
3. 为 Standard IMM 与 Gated IMM 设计统一的特征导出接口。
4. 按预测窗口缓存 IMM 轨迹、模型概率、创新和协方差。
5. 实现最小版 IMM–PatchTST 残差模型。
6. 依次加入模式概率、协方差和动态门控，并进行消融。
7. 在验证集上选择结构，冻结方案后只进行一次正式测试集评估。

## 对照与消融实验

最终实验至少应包含：

1. Position Hold；
2. Constant Velocity；
3. Standard IMM；
4. Gated IMM；
5. PatchTST Raw；
6. PatchTST Causal Smooth；
7. IMM 与 PatchTST 固定权重融合；
8. IMM + PatchTST 最小残差补偿；
9. 残差补偿 + IMM 模型概率；
10. 完整的模式感知或动态门控融合模型。

固定权重融合是必要的强对照。如果复杂门控不能稳定超过简单加权，便不能证明复杂融合机制的有效性。

## 数据和实现约束

- IMM 与 PatchTST 必须使用相同的预测原点、历史窗口和未来标签。
- 生成 IMM 特征时只能读取预测原点及其以前的观测，禁止未来信息泄漏。
- 坐标系、单位和归一化定义必须统一。
- 所有归一化统计量只能由训练集拟合。
- Causal Smooth 只能处理历史输入，不能平滑未来标签。
- IMM 输出建议离线缓存，避免每个 epoch 重复运行完整滤波流程。
- 缓存必须记录数据版本、配置哈希、subset、split、segment 和 origin，避免错配。
- Standard IMM 与 Gated IMM 应实现同一输出协议，以便公平替换和消融。
- 测试集不参与结构选择、门控阈值调整或早停。

## 评价重点

除总体误差外，应分别报告 1、5、10、20、30、60 秒预测时域的三维、水平和垂直误差，并比较：

- 稳定直飞与明显机动状态；
- 模式保持与模式切换区间；
- 正常观测与缺失、异常观测；
- 参数量、训练时间、推理延迟和显存占用；
- 多个随机种子下的均值与波动。

最终需要回答的不只是“融合是否更准”，还包括融合在什么状态和预测时域有效、IMM 内部信息贡献了多少，以及模型在什么条件下失效。

## 当前推荐结论

优先实现“模式感知的 IMM–PatchTST 残差融合模型”。它能够最大程度复用现有 IMM、PatchTST、数据划分与评价代码，融合逻辑明确、实现风险适中，也容易形成“物理基线—深度基线—最小融合—模式感知融合”的完整硕士论文实验链条。
